📥 Downloads

A subfolder name only — e.g. MediaExtractorPRO or Shows/Anime. This can never be a drive letter or full disk path (D:\Anime, C:\Users\you\Videos) — Chrome doesn't let extensions write anywhere outside the browser's own Downloads directory, full stop, so anything that looks like a drive letter gets stripped out. To actually change where Downloads itself points — e.g. a different drive entirely — set that in chrome://settings/downloads → Location; this field then adds a subfolder on top of whatever that is.
